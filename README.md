# 📘 Coaching Institute App (Android)

An Android application designed for Coaching centres to easily share study materials, sample question papers, and animated videos with students — no login required! The app also features an multiple admin control on sheets and a meeting request system with Google Sheets and Telegram integration.
To modify app for your usage contact Developer - **dhyeyp254@gmail.com**
---

## 🚀 Features

### 👩‍🎓 Student Side
- View available tuition classes in a **card-based layout**
- Tap a class card to access:
  - 📄 Notes (Google Drive link)
  - 📝 Sample Papers
  - 🎞️ Animated Videos (optional)
- Completely **login-free** experience
  - 📆 **Book a Meeting** form:
  - Collects student name and phone number
  - Saves to Google Sheet (via Sheet.best)
  - Sends real-time Telegram alert to admin


### 🧑‍🏫 Admin Side
- Edit class content: Notes, Papers, and Videos via Google Sheet
- Content is dynamically fetched using the **Sheet.best API**

### 📱 Sidebar Navigation
- 📚 **Teachers List**
- Developer Contact Details
---

## 🛠️ Tech Stack
- **Android Studio** (Java)
- **Sheet.best API** (Google Sheets as backend DB)
- **Telegram Bot API** for admin notifications
- **RecyclerView** for card UI
- **Navigation Drawer** for sidebar menu

---

## 🔐 Admin Info
- Fully Editable content via linked Google Sheet
- Get alerts for meeting request in Google Sheet and Telegram App
- Directly lists meeting requests without any hassle for students and parents
